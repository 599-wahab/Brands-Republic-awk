# Brands Republic Customer Operations

Internal customer management and business intelligence dashboard built with Next.js, TypeScript, Tailwind CSS, Recharts, and Lucide icons.

## Local development

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Production checks

Run `npm run check` to execute the product tests, linting, and an optimized production build.

## Vercel

The project uses the standard Next.js runtime and needs no custom Vercel configuration. Import the repository in Vercel or run `vercel --prod` from this directory.
